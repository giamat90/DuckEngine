## What the change does

Adds `base::math` with `Scalar` (alias of `f32`) and the plain `repr(C)` types `Vec2`, `Vec3`, `Vec4`. Every operation has a fixed evaluation order and no fused multiply-add, so results repeat bit for bit and a later SIMD path can match them. `normalized` returns an `Option`; nothing panics. Pages: `core-runtime.md` (table row, class diagram, decisions of card 1-18), `wiki/README.md` (v0.31).
