## What the change does

- `tools/arch-check/arch_check.py`: a `[[banned_use]]` rule may set `allow_in_tests = true` (default false, must be a boolean). Matches inside test-only code are then ignored: `#[cfg(test)]` items (exact spelling only), a `#![cfg(test)]` that is an inner attribute of the file itself, and files in the crate's `tests/` folder unless a non-test cargo target builds that file. The exemption is by character position, not by line.
- `gates/architecture.toml`: the key is set on the thread-creation rule only. Every other rule is unchanged.
- Wiki: `ports-and-adapters.md`, `overview.md` (threading line), `core-runtime.md` (the "cross-thread isolation not tested" note), README v0.20.
- Follow-up card 1-6: the actual cross-thread isolation test of the counting allocator.
- Not changed: production rule (threads still refused in production code of `base` and every other L0-L2 crate except `jobs` and `platform`), thresholds, workflows, digest.
