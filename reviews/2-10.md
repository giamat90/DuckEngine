# Review 2-10: ARM64 CI job on a hosted runner (governance)

Task: 2-10. Class 3 (CI workflow), goes to `main` first with a hand-started `ci` run. A follow-up docs PR into `develop` corrects the NEON statements that exist only there.
Loops: 1 of 3.
Reviewer: independent read-only subagent (general-purpose).

## Summary verdict

Ready for the owner. 0 open blocker, 0 open major. The plan changed after a probe: GitHub Free serves a hosted ARM64 runner (`ubuntu-24.04-arm`) for this private repository, so QEMU emulation is not needed. On a probe branch (`develop` plus the new job) all 14 `simd::neon::tests::*` and the 389 tests of `base` passed on a real AArch64 CPU, and clippy with `-D warnings` was clean (run 41335540584).

## What the change does

- New job `arm64` at the end of `.github/workflows/ci.yml` (on `main` and by hand): asserts `uname -m` is `aarch64`, then runs `cargo clippy --workspace --exclude 'adapter_*' --all-targets --locked -- -D warnings` and `cargo test --workspace --exclude 'adapter_*' --locked`.
- On `main` there is no NEON backend yet, so the job tests the scalar reference on ARM until `develop` is merged in.
- One workflow test, `ci-diagrams.md` (Mermaid, seven jobs), `github-plan-findings.md` (availability verified, stall fallback, scope), README v0.65.

## Findings

- Major, a stalled queue if GitHub withdraws the ARM label would leave `arm64` pending: fixed in the docs, the fallback is to cancel and report `not run: runner unavailable`, never green.
- Major, the budget claim rested on a 2-second probe: reworded to "unmeasured, assume at most Linux 1x"; the contradicting "heavy jobs" sentence corrected.
- Minor, overclaim: README and findings now say unit tests and clippy only, with the list of what is not covered (Miri, mutation, adapters, Windows on ARM, allocator path, determinism).
- Minor, the toolchain step relies on rustup being on the image: the probe passed; accepted.
- Minor, the test matches whole command strings and forbids any step `if:`; accepted, same pattern as cards 2-8 and 2-11.
