## Verification

- 27 tests, all green on Windows with Python 3.11 (`python -m unittest -q test_next_version` in `tools/release`). Each cycle had red evidence first.
- Coverage (branch): 90% line on `next_version.py`; the uncovered lines are the `main()` wrapper, which the subprocess tests run but coverage does not trace.
- Mutation: **29 of 29** hand-made mutants killed. This was a manual pass: no Python mutation tool is installed and none was added (new dependency). The `cargo-mutants` gate covers Rust, not this tool.
- Clean-code limits (rules-digest section 4): no violations (functions under 15 lines, nesting 1, at most 2 parameters, no dead code).
