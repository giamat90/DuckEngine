## Limits the owner should know

- The tests prove that both configurations build and run, **not that mimalloc serves the allocations**: the crate forbids `unsafe`, so it cannot probe the allocator, and its name function follows the Cargo feature. Deleting the `#[global_allocator]` line would not fail a test.
- `main` is scaffolding (it prints the allocator name and churns a few boxes); it has no test and is included in the (unenforced) coverage report.
- The CI run of this PR built mimalloc on both runner images (`windows-latest`, `ubuntu-latest`) and all 10 checks passed, so the C compiler is available.
