# Security policy

## Supported versions

Only the latest release (the newest tag `vX.Y.Z` and the `main` branch it was cut from) receives fixes. Older releases do not.

## Reporting a vulnerability

Report it privately through GitHub private vulnerability reporting: on the repository page open **Security**, then **Report a vulnerability**. Please include what you found, the steps to reproduce it, the version or commit, and the impact you see.

Do not open a public issue, discussion or pull request for a vulnerability, and do not post details elsewhere until a fix is released.

## What to expect

This is a one-person project with an AI coding agent. Reports are read and answered on a best-effort basis; there is no service-level agreement and no promised response or fix time. If a report is valid, it is fixed in the latest release and you are credited if you wish.

## Scope

The engine source, the tools and the GitHub workflows in this repository. Third-party libraries are reported to their own projects. If you find a secret or credential committed by mistake, report it the same way.
