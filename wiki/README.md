## Mission in one paragraph

A game engine written from scratch whose two defining properties are **Performance** (efficient at runtime, measured not assumed) and **Flexibility** (no hard dependency on any third-party physics, graphics, audio or similar library; each one sits behind a port we own, so it can be swapped). It is built with **TDD** and its quality is **measured continuously** with software metrics.
