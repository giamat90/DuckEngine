# Architecture Decision Records (ADR) - index

Entries marked "decided by owner" are decided; all others are **Proposed**. Format: context -> decision proposed -> alternatives -> how we will validate. When accepted, move to `docs/adr/` and set status.

## ADR template

```
# ADR-NNNN <title>
Status: Proposed | Accepted | Superseded by ADR-XXXX
Context: <forces, requirements>
Decision: <what>
Alternatives: <and why not>
Consequences: <good / bad>
Validation: <test, benchmark or metric that proves/disproves it>
```
